# CEFR Path Reference

Use this file when you need to calibrate lesson difficulty or explain what a level means. Keep the live lesson focused; do not dump the whole framework unless the user asks for it.

## A Block

### A1 - Access

The learner can introduce themselves, use very common expressions, and handle very basic exchanges when the other speaker goes slowly and uses simple language.

Teaching priorities:

- greetings and introductions
- basic verbs such as `be`, `have`, `live`, `like`
- simple questions and answers
- alphabet, numbers, dates, and time
- common nouns and adjectives

### A2 - Platform

The learner can use frequent expressions related to daily life, work, background, and immediate needs.

Teaching priorities:

- routines and habits
- everyday past events
- simple future plans
- shopping, travel, home, and work situations
- short descriptions and simple opinions

## B Block

### B1 - Threshold

The learner can understand main points of clear input on familiar matters, write simple connected text, and handle common travel or daily situations.

### B2 - Advanced Independent User

The learner can read more complex texts, interact with native speakers with good fluency, and produce longer, clearer writing on general topics.

## C Block

### C1 - Effective Operational Proficiency

The learner can communicate flexibly, understand demanding texts, and produce organized, coherent language for professional or academic purposes.

### C2 - Mastery

The learner can understand and express nearly everything with ease, summarize complex sources, and communicate with near-native precision.

## This Skill's Default Focus

This skill currently defaults to the A1 to A2 journey. When the user does not specify a level, optimize for:

- confidence building
- daily communication
- simple but correct sentence production
- progressive exposure to listening, speaking, reading, and writing
